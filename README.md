# MySQL 学习笔记

记录 MySQL 基础知识、SQL 语句及 Navicat 图形界面的常用操作。

## 内容

- 基础：SQL 简介、数据类型、数据库与数据表操作。
- 查询：条件、排序、分页、分组、聚合函数、多表查询与子查询。
- 进阶：约束、索引、事务、函数及用户权限管理。
- 实践：各主题中包含 Navicat 的相关操作步骤。
